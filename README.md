# EF-AI opencode 


Folder ini adalah external memory untuk pengembangan EF-AI.


## Files

PROJECT_CONTEXT.md
Project identity and goals.


ARCHITECTURE.md
System architecture.


CURRENT_STATE.md
Current progress.


DECISIONS.md
Architecture decisions.


SESSION_LOG.md
Development history.


## Usage

Before starting a new AI session:

1. Load this folder.
2. Read PROJECT_CONTEXT.md.
3. Read CURRENT_STATE.md.
4. Continue from latest SESSION_LOG.md.
